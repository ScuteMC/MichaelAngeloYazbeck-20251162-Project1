# Original artwork generation

All images were created for Lanternwake using the native OpenAI ImageGen tool, not an external asset pack or API fallback. Final files are under Assets/Lanternwake/Art. Original generated alpha channels are preserved. Game scaling and sprite import settings are handled by Unity. MenuGarden and Ground are opaque; all other images were requested on transparent backgrounds.
